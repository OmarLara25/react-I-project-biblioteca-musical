# Biblioteca Musical

## Descripción

Biblioteca Musical es una aplicación web desarrollada con React como parte de una práctica del curso de Desarrollo FullStack de EBAC.

El proyecto representa una biblioteca musical estática donde se muestran diferentes canciones junto con información básica como título, artista, álbum y duración.

La aplicación utiliza componentes de clase, JSX y props para construir y reutilizar los diferentes elementos de la interfaz.

## Tecnologías utilizadas

- React
- JavaScript
- JSX
- CSS
- Node.js
- npm

## Funcionalidades

- Mostrar el encabezado de la aplicación.
- Mostrar una lista de canciones.
- Mostrar título, artista, álbum y duración de cada canción.
- Reutilizar el componente `Song` mediante props.
- Implementar el método `componentDidMount()` para mostrar un mensaje en la consola cuando la aplicación se monta.
- Aplicar estilos básicos mediante CSS.
